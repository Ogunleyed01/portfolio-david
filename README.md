# Portfolio (Animated)

A small personal portfolio built with React and Vite, focused on simple animated UI and fast local development.

## Features

- React 18 + Vite for fast HMR and builds
- Minimal ESLint configuration (project scaffolded from Vite template)
- Static assets in `src/assets`

## Prerequisites

- Node.js 16+ or newer
- npm (or yarn/pnpm)

## Quick start

1. Install dependencies

```bash
npm install
```

2. Start development server (with HMR)

```bash
npm run dev
```

3. Build for production

```bash
npm run build
```

4. Preview the production build locally

```bash
npm run preview
```

## Project structure

- `index.html` — app entry HTML
- `src/main.jsx` — application bootstrap
- `src/App.jsx` — root React component
- `src/assets/` — images and static assets
- `vite.config.js` — Vite configuration
- `package.json` — scripts and dependencies

## Notes

- Images are stored in `src/assets`. Replace or optimize them for production as needed.
- ESLint and other tooling follow the Vite React starter defaults. Add TypeScript or additional rules if desired.
